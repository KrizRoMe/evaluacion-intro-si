# Instrucciones de la Evaluación Práctica

## ⏱️ Tiempo

**90 minutos** en clase. No es tarea para la casa.

## 🎯 El reto

Vas a explorar una nueva aplicación web y vas a **auditar** su funcionamiento como analista de Sistemas de Información.

Tu tarea es **detectar problemas reales**, justificarlos y proponer soluciones.

## 🔍 ¿Qué debes buscar?

- Problemas en los componentes o el funcionamiento del SI
- Riesgos para la información (Confidencialidad, Integridad, Disponibilidad)
- Situaciones que requieran mantenimiento (correctivo, preventivo, adaptativo, perfectivo)
- Problemas éticos
- Problemas de privacidad o protección de datos

## 📝 Entregable

**Exactamente 3 GitHub Issues** en este repositorio, usando la plantilla **"Hallazgo SI"** y la etiqueta **`hallazgo-si`**.

**No 2. No 4. No 5. Exactamente 3.**

## ✏️ Cada Issue debe incluir

1. **Hallazgo** — qué problema encontraste.
2. **Evidencia / ubicación** — dónde ocurre y cómo comprobarlo.
3. **Concepto relacionado** — qué tema de la Unidad 1 se relaciona.
4. **Justificación** — por qué es un problema.
5. **Impacto / riesgo** — qué puede ocurrir y a quién afecta.
6. **Severidad** — Baja, Media o Alta (con justificación).
7. **Propuesta** — cómo solucionarlo (concreta y razonable).

## � Recuerda

- No necesitas encontrar **todos** los problemas.
- **La calidad del análisis importa más que la cantidad.**
- Selecciona tus **3 mejores hallazgos**.
- Puedes explorar la aplicación libremente: no hay un orden correcto.
- No necesitas conocimientos avanzados de programación.
- Usa tus propias palabras. La claridad es más importante que la terminología técnica.

## 💡 Conceptos que puedes aplicar

- Definición de Sistema de Información (Laudon)
- Modelo Entrada → Proceso → Salida
- Los 6 componentes: Personas, Datos, Software, Hardware, Redes, Procesos
- Tipos de SI: TPS, MIS, DSS, ESS
- Roles en un SI: CIO, Arquitecto, Analista, Desarrollador, Admin BD, Soporte
- Proceso vs Procedimiento
- Administración de SI
- Riesgos CID (Confidencialidad, Integridad, Disponibilidad)
- Mantenimiento: Correctivo, Preventivo, Adaptativo, Perfectivo
- Triada Técnico → Legal → Ético
- Privacidad vs Seguridad
- Datos personales y tratamiento de datos
- Ley N° 29733 y sus principios
- Derechos ARCO (Acceso, Rectificación, Cancelación, Oposición)
- Responsabilidad organizacional

## 🚫 Lo que NO debes hacer

- No crear Issues que no describan un problema real.
- No inventar problemas que no puedas justificar con evidencia.
- No usar la Issues para hacer consultas o preguntas al docente.
- No modificar el código de la aplicación.
