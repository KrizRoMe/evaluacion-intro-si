## Rúbrica de cada Issue (6 puntos)

### 1. Identificación del hallazgo (1 punto)

| Puntaje | Descripción |
|---|---|
| 1.0 | El problema existe en la aplicación y está claramente identificado. |
| 0.5 | El problema existe pero la descripción es poco precisa. |
| 0 | El problema no existe o no se entiende. |

### 2. Evidencia / ubicación (1 punto)

| Puntaje | Descripción |
|---|---|
| 1.0 | Permite localizar y comprobar el problema (página + acción o interacción). |
| 0.5 | La ubicación es parcialmente clara o falta el "cómo comprobarlo". |
| 0 | No permite comprobarlo. |

### 3. Concepto relacionado (1.5 puntos)

| Puntaje | Descripción |
|---|---|
| 1.5 | Relaciona correctamente el hallazgo con un concepto visto y explica la relación. |
| 1.0 | El concepto es correcto pero la explicación es superficial. |
| 0.5 | La relación es parcialmente correcta. |
| 0 | No existe una relación válida o menciona un concepto equivocado. |

### 4. Justificación e impacto (1 punto)

| Puntaje | Descripción |
|---|---|
| 1.0 | Explica claramente por qué es un problema y sus consecuencias. |
| 0.5 | El impacto es razonable pero superficial. |
| 0 | No explica el impacto. |

### 5. Severidad (0.5 puntos)

| Puntaje | Descripción |
|---|---|
| 0.5 | Severidad razonable y justificada. |
| 0.25 | Severidad razonable pero débilmente justificada. |
| 0 | Severidad incoherente con el problema descrito. |

### 6. Propuesta de solución (1 punto)

| Puntaje | Descripción |
|---|---|
| 1.0 | Solución concreta y razonable. |
| 0.5 | Solución general pero razonable. |
| 0 | No propone solución o es incorrecta. |

---

## Calidad global (2 puntos)

### Aplicación de conocimientos (1 punto)

Evalúa si las 3 Issues demuestran comprensión de los contenidos de la Unidad 1.

| Puntaje | Descripción |
|---|---|
| 1.0 | Buena aplicación de los contenidos. |
| 0.5 | Aplicación limitada pero suficiente. |
| 0 | Poca relación con la unidad. |

### Calidad global del análisis (1 punto)

Evalúa la coherencia entre problema, concepto, impacto, riesgo y solución.

| Puntaje | Descripción |
|---|---|
| 1.0 | Existe coherencia entre las 3 Issues y cada Issue en sí. |
| 0.5 | Los hallazgos son válidos pero superficiales. |
| 0 | Existe poca comprensión. |

## Escala de aprobación

| Nota | Estado |
|---|---|
| 18–20 | Excelente |
| 16–17 | Muy bueno |
| 14–15 | Bueno (aprueba) |
| 11–13 | Desaprueba |
| 0–10 | Desaprueba |

**Aprobación mínima: 14/20.**
