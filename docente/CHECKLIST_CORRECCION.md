# Checklist de Corrección — Evaluación Práctica

## Antes de corregir

- [ ] Tener a mano `RUBRICA.md`
- [ ] Tener a mano `RESPUESTAS_ESPERADAS.md`
- [ ] Tener a mano `PROMPT_CORRECCION_IA.md`
- [ ] Identificar al estudiante (nombre, código)

## Revisión de Issues

- [ ] El estudiante creó **exactamente 3 Issues**
- [ ] Las 3 Issues están accesibles (públicas o visibles)
- [ ] Cada Issue usa la plantilla "Hallazgo SI"
- [ ] Cada Issue tiene la etiqueta `hallazgo-si`

## Evaluación por Issue

Para cada Issue, verificar:

- [ ] **Hallazgo:** el problema existe y está claramente identificado (1 punto)
- [ ] **Evidencia:** la ubicación permite localizar y comprobar el problema (1 punto)
- [ ] **Concepto:** está relacionado correctamente con un tema de la Unidad 1 (1.5 puntos)
- [ ] **Justificación:** explica por qué es problema y sus consecuencias (1 punto)
- [ ] **Severidad:** razonable y justificada (0.5 puntos)
- [ ] **Propuesta:** solución concreta y razonable (1 punto)

**Subtotal esperado: 6 puntos por Issue.**

## Evaluación global

- [ ] **Aplicación de conocimientos:** las 3 Issues muestran comprensión de la Unidad 1 (1 punto)
- [ ] **Calidad del análisis:** coherencia entre problema, concepto, impacto y solución (1 punto)

**Subtotal esperado: 2 puntos.**

## Suma final

- [ ] Issue 1: ___ / 6
- [ ] Issue 2: ___ / 6
- [ ] Issue 3: ___ / 6
- [ ] Calidad global: ___ / 2
- [ ] **TOTAL: ___ / 20**

## Aprobación

- [ ] Si total >= 14: **APROBADO**
- [ ] Si total < 14: **DESAPROBADO**

## Retroalimentación

- [ ] Generar retroalimentación escrita para el estudiante
- [ ] Mencionar puntos fuertes
- [ ] Sugerir áreas de mejora si aplica
- [ ] No usar lenguaje punitivo

## Verificación final

- [ ] Nota registrada correctamente
- [ ] Suma verificada dos veces
- [ ] Retroalimentación entregada al estudiante
- [ ] Archivo de evaluación guardado (si aplica)
